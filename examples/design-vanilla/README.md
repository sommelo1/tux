# checkout (vanilla design)

Choose one TUX CLI variant. With Node.js, run `npm install --save-dev
tux-review` in this project and use `npx tux …`. With Python, install
`tux-review` using `pipx` or `pip` and use `tux …`. The commands are otherwise
identical.

```bash
# Node.js/npm variant
npx tux design start-review --foreground --dir .

# Python/PyPI variant
tux design start-review --foreground --dir .
```

Routes: `/`, `/products` (tabs), `/checkout` (modal).
